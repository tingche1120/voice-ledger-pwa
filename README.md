# 日日記帳 Voice Ledger PWA

一個 iPhone 可用的 PWA 記帳 app 原型。目標是打開 app 後，可以用文字或語音快速記帳，先以本機資料與手動備份完成 A1.0，之後再接登入與雲端同步。

## 目前進度

目前版本：`A1.3.8`

已完成 A1.0 原型，A1.3 加入 AI 解析與中文 / English 語音語言切換：

- 可加入 iPhone 主畫面的 PWA。
- 首頁包含月曆、快速記帳、本月支出、本月收入、結餘與選取日期紀錄。
- 日曆區可左右滑動切換月份，左滑往後一個月，右滑往前一個月，跨年會自動更新年份。
- 日曆下方顯示選取日期當天的收支與筆數，明細按鈕開啟當月明細。
- 支援文字快速輸入與多筆解析，金額可在品項前或品項後，例如 `午餐100`、`100 午餐 200星巴克`、`200早餐300星巴克 午餐200`。
- 支援日期解析，例如 `昨天午餐200`、`24號午餐100`、`4月25午餐500`、`四月25午餐500`、`2026/2/10保險3000`，也會保留 `8月到10月` 這類期間文字，不把其中的月份當成金額。
- 支援確認視窗，可在儲存前修改類型、金額、分類、日期、備註，也可刪除候選筆數。
- 支援紀錄列表、編輯、刪除、搜尋、月份明細。
- 支援統計頁，顯示本月支出分類長條與圓餅比例。
- 支援自訂分類與關鍵字，設定頁可進入編輯模式新增、刪除、修改關鍵字。
- 支援 JSON 備份、JSON 還原與 CSV 匯出。
- 已加入 PWA icon 與 iPhone 主畫面名稱。
- 目前作為個人測試用 PWA，不在 README 公開部署網址。

## 核心紀錄

### 技術方向

- 第一版是純前端 PWA。
- 主要檔案：
  - `index.html`
  - `styles.css`
  - `app.js`
  - `manifest.webmanifest`
  - `service-worker.js`
  - `icons/`
- 本機靜態伺服器：`server.js`
- 本機網址：

```text
http://localhost:4173
```

- 手機同 Wi-Fi 測試網址依電腦 IP 而定，例如：

```text
http://<你的電腦區網 IP>:4173/
```

### 資料保存方式

目前資料存在使用者裝置的 `localStorage`，不同使用者不會互相看到資料。

目前沒有雲端同步。換手機時請使用：

- `備份 JSON`：完整備份紀錄、分類、關鍵字
- `還原 JSON`：換手機或重裝後還原
- `匯出 CSV`：給 Numbers / Excel 查看

### 快速記帳解析

支援範例：

```text
午餐100
午餐一百 星巴克兩百
早餐80 午餐120 晚餐200
昨天午餐200 今天晚餐300
4月25午餐500
四月25午餐500
四月二十五號午餐500
2026/2/10保險3000
```

金額支援：

- 阿拉伯數字：`100`、`3000`
- 中文口語金額：`一百五`、`三千二`、`五萬八`

### 日期規則

- 沒有指定日期時，使用目前日曆選取日期。
- 只說 `24號` 或 `24日` 時，使用目前日曆停留的年月。
- 說 `昨天`、`今天`、`明天`、`前天`、`大前天`、`後天`、`大後天` 時會自動對應相對日期。
- 說 `4月25` 或 `四月25` 時，年份使用目前日曆選取的年份。
- 說 `2026/2/10` 或 `2026年4月25` 時，使用輸入中的年份。

### 語音輸入現況

網頁語音辨識依瀏覽器支援度而定。iPhone Safari / PWA 對 Web Speech 支援不穩，尤其在區網 HTTP 測試時更有限。

目前 fallback：

- 支援 Web Speech 時：綠色按鈕可按住說話，放開解析。
- 不支援 Web Speech 時：按綠色按鈕會 focus 文字輸入框，讓 iPhone 鍵盤跳出，再由使用者按鍵盤上的麥克風 dictation。

若語音失敗，可到「設定 → 語音診斷（暫時）」按「複製診斷紀錄」。紀錄只保留在本次開啟的 App 記憶體中，包含語音啟停事件、瀏覽器錯誤代碼與 AI 請求狀態，不包含語音內容或記帳資料；重新開啟 App 就會清除。

A1.3.7 暫時在同一份診斷紀錄追蹤確認視窗內的觸控目標、點擊座標、焦點、可視畫面高度，以及提示訊息是否覆蓋儲存按鈕。事件以 `[DEBUG-save-a137]` 開頭，只記錄介面狀態與待儲存筆數，不記錄帳目內容。用來找出手機上需要按兩次時，第一下實際被哪個介面攔走。

A1.3.8 針對 iPhone 第一次有橘色麥克風指示、後續只有網頁 `audio-start` 卻沒有橘點的現象，改為每輪建立全新的辨識器，結束後清除所有回呼、呼叫 `abort()` 並丟棄舊物件。若 `audio-start` 後 5 秒仍沒有語音事件，會以 `mic-watchdog-timeout` 記錄並中止該次辨識。這是改用錄音上傳前的最後一個 Web Speech 釋放實驗，是否有效仍以 iPhone 橘點與連續實測為準。

語音辨識模式可在設定中切換：「目前模式」維持原有持續辨識；「單句模式（實驗）」用來比較 iPhone 上連續錄音的穩定性，可能在說話停頓時提前結束。選擇會保留在這台裝置，可隨時切回目前模式；診斷紀錄會標明每次使用的模式。

解析方式可切換「AI 解析」與「本機解析（測試）」。本機模式完全略過 AI 網路請求並立即使用既有規則解析，兩種方式共用相同的語音辨識程式，用來 A/B 比較 AI 等待是否會影響下一次錄音。選擇會保留在這台裝置，診斷紀錄的 `parser=ai` / `parser=local` 及 `AI` / `LOCAL` 事件可確認實際走的路徑。

A1.3.4 曾測試在同一次開啟 App 期間重複使用同一個辨識器；A1.3.8 已依 iPhone 橘點證據改為相反策略，每輪完整釋放並重建。收到 error 後仍會等 end 才允許重新啟動，各輪文字與回呼狀態分開保存，重複的停止要求只會送出一次。此調整仍需 iPhone 實測確認，不能把模擬測試通過當成手機問題已排除。

檢查指令：`node tests/parser-mode.test.cjs`、`node tests/parser-regression.test.cjs`、`node tests/voice-lifecycle.test.cjs`、`node tests/voice-mode.test.cjs` 與 `node tests/save-touch-diagnostics.test.cjs`。測試使用實際 app.js 流程與模擬語音／HTTP 事件，涵蓋 AI／本機解析隔離、既有解析基線、兩種語音模式、儲存及取消後連續三筆、每輪辨識器釋放、麥克風逾時保護、錯誤與結束事件間隔、重複停止、舊回呼隔離及儲存觸控診斷；不會測到 iPhone 原生辨識服務。

### 分類與關鍵字

預設分類包含：

```text
餐飲、交通、購物、生活、娛樂、醫療、教育、保險、房租 / 房貸、貸款、薪資、退款、其他
```

自動分類使用關鍵字比對，並採用較長關鍵字優先。例如 `買課程` 會優先分類為 `教育`，不會被 `購物` 的 `買` 搶走。

教育分類目前關鍵字：

```text
補習、買課程、課程、學費、教材、書籍、考試、報名費、家教
```

使用者可在設定頁按 `分類與關鍵字 -> 編輯` 自行新增分類、修改關鍵字或刪除分類。

### 搜尋

月曆右上角搜尋按鈕會開啟搜尋面板。

搜尋範圍：

- 日期
- 備註
- 分類
- 類型：收入 / 支出

搜尋結果會列出所有符合資料，每筆顯示：

```text
日期｜備註 / 分類｜金額
```

點擊搜尋結果會跳到該日期。

## 本機開發

啟動本機 server：

```powershell
cd <project-folder>
node server.js
```

打開：

```text
http://localhost:4173
```

如果要讓手機連進電腦測試，手機和電腦需在同一個私人 Wi-Fi，並確認 Windows 防火牆允許 TCP `4173`。測試完成後可關閉本機 server。
